# 📁 文件夹收纳专家 - FolderSorter Pro

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Windows](https://img.shields.io/badge/Platform-Windows-blue.svg)](https://www.microsoft.com/windows)

> 一款专为 Windows 用户设计的文件整理工具，一键自动归类、批量重命名、查重删除。

## ✨ 核心功能

### 🔄 自动整理
选择任意文件夹，一键按**扩展名 / 文件大小 / 修改日期**自动归类：
- 📄 按扩展名：PDF/图片/视频/文档自动分文件夹
- 📊 按大小：微小文件 / 小文件 / 大文件
- 📅 按日期：按月份归档，告别混乱

### ✏️ 批量重命名
强大模板语法，批量修改文件名：
```
{name}  → 原文件名
{ext}   → 扩展名
{date}  → 修改日期(YYYYMMDD)
{num}   → 序号(001, 002...)
{size}  → 文件大小
```

### 🔍 重复文件检测
基于 MD5 哈希精确查重，释放硬盘空间

### 📋 规则管理
自定义规则，保存为 `.fsrule` 文件复用
